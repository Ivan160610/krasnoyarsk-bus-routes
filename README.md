# Маршруты Красноярска

Интерактивная карта четырёх служебных маршрутов. День: въезд на базу в 05:45; ночь: в 17:45.

При выборе каждого маршрута открывается таблица остановок по порядку движения с отдельной колонкой времени выбранной смены. На телефоне есть переключение между картой и расписанием. Нажатие на остановку показывает её на карте. Попутные остановки без посадки отмечены прочерком; в конце указаны въезд на базу и высадка. Поиск, названия точек и пешие подходы сохранены. Маршрут 2 проходит через улицу Крупской без заезда к Почте.

Карта работает автономно: откройте `index.html` в браузере. Фамилии и индивидуальное распределение сотрудников по сменам в файл не включены. Число людей относится ко всему списку. Время расчётное, без текущих пробок. Данные карты: © OpenStreetMap contributors; маршруты: OSRM.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
