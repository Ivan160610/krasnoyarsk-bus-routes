# Маршруты Красноярска

«На смену» — интерактивная карта четырёх служебных маршрутов. День: въезд на базу в 05:45; ночь: в 17:45.

Цветные карточки маршрутов, переключатель смены, фильтры «Все остановки / Посадка / Пешком», поиск с очисткой и выделение выбранной остановки. Карточка на карте показывает крупное время посадки и позволяет вернуться к расписанию. При выборе каждого маршрута открывается таблица остановок по порядку движения с отдельной колонкой времени выбранной смены. На телефоне есть переключение между картой и расписанием. Нажатие на остановку показывает её на карте. Попутные остановки без посадки отмечены прочерком; в конце указаны въезд на базу и высадка. Поиск, названия точек и пешие подходы сохранены. Маршрут 2 проходит через улицу Крупской без заезда к Почте.

Маршруты и расписание доступны автономно: откройте `index.html` в браузере. Фамилии и индивидуальное распределение сотрудников по сменам в файл не включены. Число людей относится ко всему списку. Время расчётное, без текущих пробок. Данные карты: © OpenStreetMap contributors; маршруты: OSRM.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Поиск остановки по адресу

Кнопка «Найти остановку по адресу» открывает поиск дома в Красноярске и окрестностях. Система сравнивает пешие расстояния до 43 назначенных мест посадки, показывает три ближайших варианта, минуты ходьбы и время автобуса выбранной смены. Можно ограничить поиск одним маршрутом. Попутные точки без назначенной посадки не предлагаются как места посадки.

Если найден только ориентир улицы, точный дом не подменяется её серединой: предлагается уточнить положение вручную на карте. Пеший путь отображается пунктиром от адреса до посадки. При отказе сервиса расстояния по прямой подписаны отдельно, минуты ходьбы не выдумываются. Если ближе 15 минут посадки нет, интерфейс сообщает об этом.

Адресный поиск и новые пешие пути требуют интернета. Запрос геокодирования выполняется только после нажатия «Найти»; повторные результаты кешируются в памяти открытой страницы. Адреса не записываются в репозиторий, локальное хранилище или систему аналитики. Сначала дом ищется в публичном справочнике адресов, встроенном в HTML. Если совпадения нет, запрос поиска отправляется Photon. Координаты для пешего расчёта отправляются FOSSGIS OSRM.

Геокодер: [Photon](https://github.com/komoot/photon), публичный сервис https://photon.komoot.io/api/. Допускается умеренное использование, доступность не гарантируется; запросы ограничены и кешируются. API пеших путей: https://routing.openstreetmap.de/routed-foot. Оба адреса сервиса настраиваются в объекте `addressServices`. Документация: [Photon API](https://github.com/komoot/photon/blob/master/docs/api-v1.md), [OSRM API](https://project-osrm.org/docs/v5.5.1/api/).

## Подробная карта и номера домов

Подложка — подробная OpenStreetMap с дорогами, зданиями и пешеходными дорожками. При приближении загружаются новые тайлы вплоть до масштаба 19; колесо приближает к курсору, на телефоне доступны жесты и кнопки. При крупном масштабе поверх карты видны номера домов: на номер можно нажать и найти ближайшую посадку. Кнопка «Мой дом» приближает адрес, «Весь путь» возвращает весь пеший подход.

Публичный справочник содержит 50 506 адресных точек в Красноярске и окрестностях. Выгрузка OpenStreetMap: 13.10.2026, 04:23:36 UTC. Номера и координаты получены из данных OSM; покрытие зависит от заполненности карты. Отсутствующий номер не выдумывается. Крупской, 32 находится как конкретный дом; одноимённая улица Надежды Крупской учитывается отдельно. Номер квартиры игнорируется.

Данные адресного справочника: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright). Справочник находится в HTML в блоке `housedata`: gzip/base64 JSON с таблицами `streets`, `cities`, `rows`; формат строки — индекс улицы, номер дома, индекс города, широта, долгота. Он содержит только публичные адресные данные OSM, без ФИО и адресов из кадровых таблиц.

Подробная подложка и пеший расчёт требуют интернета; встроенные маршруты, расписание и адресный справочник доступны из HTML. Тайлы загружаются только для текущего экрана, обычный HTTP-кеш браузера сохраняется. URL тайлов настраивается в объекте `mapServices`. [Правила сервиса тайлов](https://operations.osmfoundation.org/policies/tiles/). Это карта OpenStreetMap; подключение MapGL 2ГИС потребует ключа Map Tiles API владельца сайта.

## Редактор администратора

Откройте `admin.html` на сайте. Маршруты и остановки хранятся в `routes.json` отдельно от интерфейса. Карта сотрудников загружает опубликованные данные при открытии и проверяет обновления раз в минуту, пока вкладка видима. Последняя проверенная версия сохраняется для временного отсутствия сети; при этом интерфейс сообщает об отсутствии связи.

Редактор позволяет менять названия, типы и порядок остановок, времена дневной и ночной посадки, координаты, пешие привязки и проездные точки. Маркер можно перетащить, автобусный путь перестроить по дорогам, пешие подходы пересчитать. Попутные остановки можно обновить из публичного каталога OSM. Контрольный въезд 05:45 / 17:45 защищён. Перед публикацией проверяются маршруты, порядок времени, наличие посадок и привязки пеших путей. Есть черновик в браузере, отмена/повтор, резервная копия JSON, предпросмотр и восстановление предыдущих публикаций в черновик.

Для публикации прямо из редактора владелец Ivan160610 подключает свою учётную запись ключом GitHub Fine-grained PAT: Only select repositories → krasnoyarsk-bus-routes, Contents → Read and write. Ключ хранится только в памяти вкладки, не записывается в localStorage, резервные копии и репозиторий. GitHub проверяет фактические права записи. Текущая сессия редактора ограничена 30 минутами без запросов к GitHub; после перезагрузки страницы нужно подключиться вновь.

Без ключа можно редактировать черновик и использовать «Через GitHub»: скопировать подготовленные данные в редактор файла routes.json и выполнить Commit changes под своей учётной записью с правом записи. Отдельному администратору нужно предоставить доступ к репозиторию GitHub; права не выдаются одним лишь открытием admin.html. Fine-grained PAT GitHub сейчас ограничен для внешних collaborators, поэтому для такого пользователя предусмотрена обычная публикация через GitHub. Пароля, спрятанного в HTML, нет.

Автоматическая публикация редактора использует REST Contents API, проверяет SHA исходного routes.json и блокирует замену, если другой администратор уже изменил этот файл. Каждое сохранение — отдельный коммит с описанием; после сохранения редактор ожидает появление версии на GitHub Pages. Восстановление не сбрасывает историю репозитория: выбранная версия становится черновиком и публикуется новым коммитом.

Схема данных: schemaVersion=1; revision; updatedAt; updatedBy; gateDay/gateNight; routes; points; walks. У точек постоянные id, у пеших путей fromId/toId; у проездных точек afterId задаёт посадку, после которой нужно проехать. Обновляйте сайт вместе с актуальным routes.json. Приватные кадровые таблицы и ФИО не публикуются.

Инструкция: [GitHub PAT](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens), [Contents API](https://docs.github.com/en/rest/repos/contents).
