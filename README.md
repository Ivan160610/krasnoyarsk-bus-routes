# Маршруты Красноярска

«На смену» — интерактивная карта четырёх служебных маршрутов. День: въезд на базу в 05:45; ночь: в 17:45.

Цветные карточки маршрутов, переключатель смены, фильтры «Все остановки / Посадка / Пешком», поиск с очисткой и выделение выбранной остановки. Карточка на карте показывает крупное время посадки и позволяет вернуться к расписанию. При выборе каждого маршрута открывается таблица остановок по порядку движения с отдельной колонкой времени выбранной смены. На телефоне есть переключение между картой и расписанием. Нажатие на остановку показывает её на карте. Попутные остановки без посадки отмечены прочерком; в конце указаны въезд на базу и высадка. Поиск, названия точек и пешие подходы сохранены. Маршрут 2 проходит через улицу Крупской без заезда к Почте.

Маршруты и расписание доступны автономно: откройте `index.html` в браузере. Фамилии и индивидуальное распределение сотрудников по сменам в файл не включены. Число людей относится ко всему списку. Время расчётное, без текущих пробок. Данные карты: © OpenStreetMap contributors; маршруты: OSRM.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Поиск остановки по адресу

Кнопка «Найти остановку по адресу» открывает поиск дома в Красноярске и окрестностях. Система сравнивает пешие расстояния до 43 назначенных мест посадки, показывает три ближайших варианта, минуты ходьбы и время автобуса выбранной смены. Можно ограничить поиск одним маршрутом. Попутные точки без назначенной посадки не предлагаются как места посадки.

Если найден только ориентир улицы, точный дом не подменяется её серединой: предлагается уточнить положение вручную на карте. Пеший путь отображается пунктиром от адреса до посадки. При отказе сервиса расстояния по прямой подписаны отдельно, минуты ходьбы не выдумываются. Если ближе 15 минут посадки нет, интерфейс сообщает об этом.

Адресный поиск и новые пешие пути требуют интернета. Запрос геокодирования выполняется только после нажатия «Найти»; повторные результаты кешируются в памяти открытой страницы. Адреса не записываются в репозиторий, локальное хранилище или систему аналитики. Запрос поиска отправляется Photon, координаты для пешего расчёта — FOSSGIS OSRM.

Геокодер: [Photon](https://github.com/komoot/photon), публичный сервис https://photon.komoot.io/api/. Допускается умеренное использование, доступность не гарантируется; запросы ограничены и кешируются. API пеших путей: https://routing.openstreetmap.de/routed-foot. Оба адреса сервиса настраиваются в объекте `addressServices`. Документация: [Photon API](https://github.com/komoot/photon/blob/master/docs/api-v1.md), [OSRM API](https://project-osrm.org/docs/v5.5.1/api/).
