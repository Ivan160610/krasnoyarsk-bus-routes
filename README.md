# На смену — Красноярск

[Карта сотрудников](https://ivan160610.github.io/krasnoyarsk-bus-routes/) · [Вход администратора](https://krasnoyarsk-route-portal.speedytiger.chatgpt.site/login) · [Первичная активация](https://krasnoyarsk-route-portal.speedytiger.chatgpt.site/activate)

Администратор входит по логину **Ivan160610** и своему паролю. Пароль владелец задаёт лично при активации, подтвердив владение картой через свою учётную запись ChatGPT. В кабинете можно создавать маршруты с нуля, добавлять остановки по адресу или на карте, менять порядок, задавать время дневной и ночной посадки, строить путь по дорогам и сохранять изменения кнопкой «Опубликовать».

Маршруты хранятся в серверной базе D1. Карта GitHub получает актуальные данные из неё при открытии и раз в минуту. Доступны история, восстановление, резервные копии, отмена действий и предпросмотр. Въезд на базу остаётся 05:45 / 17:45.

Готовые маршруты №1–4 защищены от случайного изменения. Свой дополнительный маршрут можно собрать вручную из городских остановок или собственных точек. Незаполненное время не мешает предпросмотру; пунктир обозначает эскиз. Перед публикацией нужно построить линию по дорогам и проверить расписание. Уже поставленную точку можно перенести на выбранную городскую остановку.

Слой «Городские остановки» показывает 1 319 объектов OpenStreetMap в Красноярске и окрестностях, выгрузка от 14.10.2026, включая точки без названия. На отдалённом масштабе точки объединяются в группы; при приближении можно выбрать отдельную остановку. Каталог распространяется по ODbL 1.0.

`index.html` — карта. `admin.html` ведёт в личный кабинет. `routes.json` в этом репозитории — исходная архивная копия четырёх маршрутов; рабочие данные обновляются на сервере. Правки JSON в GitHub не требуются.

ФИО и кадровые таблицы в сайт не включены. Подробная карта, номера домов и адресный справочник: OpenStreetMap. Пешие пути и линии по дорогам рассчитывает OSRM; время расчётное, текущие пробки не учитываются. Номера домов зависят от данных OpenStreetMap.

Для просмотра карта доступна по ссылке с любого устройства; сохранение маршрутов сервер разрешает только администратору после входа.
