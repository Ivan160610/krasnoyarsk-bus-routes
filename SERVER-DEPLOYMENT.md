# Кабинет для будущего сервера

По решению владельца от 14.10.2026 карта пока остаётся на [GitHub Pages](https://ivan160610.github.io/krasnoyarsk-bus-routes/). Перенос кабинета на отдельный сервер отложен.

[route-portal-server.zip](./route-portal-server.zip) — подготовленная автономная версия: карта, четыре готовых маршрута, каталог городских остановок, создание дополнительных маршрутов и вход администратора по логину и паролю. Инструкция по размещению находится внутри архива в `README.md`.

Архив не запускает сервер в GitHub Pages. Рабочий кабинет пока расположен на прежнем портале; в сети владельца для входа требуется VPN. После выбора сервера нужно разместить пакет, лично задать пароль, перенести актуальные данные и проверить доступ из сети сотрудников. Только после проверки меняются ссылки на кабинет и источник маршрутов.

Пакет содержит исходную копию четырёх опубликованных маршрутов. Реальные пароли, хеши, сессии, база администратора, ФИО и кадровые таблицы в архив не включены. Перед переносом сверить маршруты с последней опубликованной версией; черновики сохранить и перенести средствами кабинета.

Проверены вход и выход, сохранение нового маршрута в SQLite, защита маршрутов №1–4, конфликт одновременных изменений, история и CSRF. В локальном интерфейсе также проверены добавление городской остановки и предпросмотр без заполненного времени.
