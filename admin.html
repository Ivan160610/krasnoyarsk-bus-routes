Технический администратор

Права подтверждены GitHub. Ключ действует только в открытой вкладке.

Публиковать изменения может владелец репозитория карты или пользователь с правом записи. Укажите ключ доступа своей учётной записи GitHub.

Ключ передаётся только GitHub, не сохраняется в файлах, черновиках и хранилище браузера.
Настроить доступ владельцу Ivan160610
  1. Откройте создание ключа GitHub ↗.
  2. В «Repository access» выберите «Only select repositories» и только krasnoyarsk-bus-routes.
  3. Разрешение «Contents» — Read and write. Создайте ключ и вставьте его в это окно.

Если администратор — другой пользователь GitHub, можно публиковать через редактор GitHub с его учётной записью и правом записи. Этот способ доступен в окне проверки изменений.

Опубликованные версии

Восстановление загружает выбранную версию в черновик. Сотрудники увидят её после проверки и новой публикации.

Публикация через GitHub

Этот способ использует обычный вход в GitHub и не требует ключа в редакторе. Скопируйте подготовленные данные, откройте файл и замените его содержимое. Затем нажмите в GitHub «Commit changes».

Открыть файл в GitHub ↗

Перед заменой проверьте, что в GitHub показана та же версия, от которой создан черновик: . Если файл уже изменён другим администратором, загрузите актуальную версию в редакторе.

Проверка времени посадок

После изменения линии проверьте время между посадками. Если нужен новый расчёт с запасом, используйте «Рассчитать время посадок» в разделе линии маршрута.

Как работать с редактором

1
Выберите маршрут и остановкуМеняйте название, тип и время в карточке справа. «Проезд без посадки» остаётся без времени.
2
Настройте движение на картеПеретащите посадку или добавьте точку проезда. В разделе «Линия маршрута» перестройте путь по дорогам и пересчитайте затронутые пешие подходы.
3
Проверьте черновикИзменения сохраняются в браузере. Доступны отмена, резервная копия, история и предпросмотр того, что увидят сотрудники.
4
Опубликуйте новую версиюНажмите «Опубликовать», проверьте список изменений и подтвердите. Сайт обновляется через GitHub; открытые карты проверяют обновления раз в минуту.
